# 📄 RetroBill Pro - Classic 2000 Edition
> **A High-Performance, Privacy-Focused Billing System with a Vintage Windows 98 Aesthetic.**

---

## 🛠️ Technical Overview
This project isn't just about nostalgia; it’s built with the precision of a systems developer. As someone who works with **Rust, Python, and C++**, I designed this tool to be fast, reliable, and completely private.

*   **Privacy-First Architecture:** All data operations are handled client-side using **IndexedDB**. 
*   **Zero Dependencies:** No cloud, no tracking, and no data leaks—your information stays in your browser.
*   **Performance:** Crafted with pure HTML, CSS, and Vanilla JavaScript for instant loading and maximum efficiency.
*   **Security Mindset:** Leveraging experience in encryption and data obfuscation, I ensured the financial data stays within a secure local sandbox.

## 🚀 Key Features
*   **Dynamic Currency Support:** Handles **EGP, USD, EUR, JPY, RUB, KWD, and SAR** with localized formatting.
*   **Full Invoice Archiving:** A built-in local database for saving, searching, and managing your invoice history.
*   **Data Portability:** Export and import your entire database as **JSON** files for manual backups.
*   **Custom Branding:** Support for local logo uploads to maintain professional identity.
*   **Print-Optimized:** Dedicated CSS media queries for perfect PDF generation and physical printing.

## 📂 Project Structure
*   **`Retro[classic] invoice.html`**: The monolithic core containing the UI, styling, and high-performance logic.
